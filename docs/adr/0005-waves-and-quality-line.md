# 5. Delivery in waves with a quality line

- Status: accepted
- Date: 2026-10-13

Closed beta starts **2026-11-24**. Scope is split into waves (see `docs/prd/README.md`); the target is waves 1–3 for the beta start, wave 4 (community, marketplace, map) in Jan–Feb 2027. On **2026-11-17** we draw a quality line: anything not at the bar in `docs/prd/quality.md` is not shipped half-done, it moves to a December wave. Cut order (first to move): gamification → delegation UI → groups → analytics → nutrition; wave 1 is never cut.

We chose this over "everything by 24.11 as it comes" (would ship raw features to the first, unrepeatable impression of the co-founder's trainers) and over moving the date (the product owner wants real users in November). The data model covers all waves from day one, so later waves add features without rewriting tables.
