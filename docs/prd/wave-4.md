# Волна 4 — «Сообщество и поиск»

Источник решений: [`docs/decisions.md`](../decisions.md) (Q1, Q47, Q48, Q49, Q51, Q52, Q53). Термины: [`CONTEXT.md`](../../CONTEXT.md). Планка качества и DoD: [`quality.md`](./quality.md).
Срок: **январь–февраль 2027**. Модель данных под сообщество и каталог закладывается с волны 1 (Q47).

## Цель

DaFit становится местом, где люди делятся тренировками, находят партнёров для занятий и тренеров рядом, а тренеры получают новых клиентов из каталога — без риска для приватности.

Сигналы успеха волны (допущение): ≥ 20% активных пользователей открывают **ленту** еженедельно; ≥ 1 пробное занятие через каталог на тренера в месяц.

## Общие правила волны

- **Данные тела, питания и фото прогресса никогда не попадают в ленту автоматически** (Q48). Автопосты — только достижения и только с подтверждения.
- **Точная позиция пользователя никогда не хранится** (Q49, Q52). Сервер получает и хранит только грубую область (см. раздел 3); расстояния показываются приближённо.
- Публичный профиль — по согласию: при первом входе в раздел «Сообщество» пользователь выбирает видимость профиля (все / подписчики / никто — допущение) и отображаемое имя.
- Блокировка и жалоба доступны на любом пользователе, посте, комментарии, клубе, отзыве.
- Возраст: функции поиска бадди — только 18+ (Q49); лента — 16+ (допущение) с обязательным подтверждением даты рождения.

## 1. Лента, стена, подписки

### Истории
- Пользователь: публикую пост о тренировке и вижу посты тех, на кого подписан.
- Пользователь: решаю, кто видит каждый пост — все, подписчики или только я.
- Клиент: получил значок — приложение предлагает опубликовать, я подтверждаю или отказываюсь.
- Тренер: веду **стену** как витрину и набираю подписчиков.

### Правила
1. **Пост**: текст до 2000 символов, до 10 изображений (допущение), необязательно — вложенный **лог тренировки** (упражнения и подходы без привязки к данным тела), значок, рекорд, **челлендж**.
2. Видимость поста (Q48): **все** / **подписчики** / **только я**; по умолчанию — значение из настроек пользователя, изначально «подписчики» (допущение).
3. **Стена** — посты пользователя в профиле с учётом видимости для смотрящего.
4. **Лента** — посты тех, на кого подписан, в обратном хронологическом порядке (допущение: без алгоритмического ранжирования в волне 4) + собственные посты.
5. **Подписка** односторонняя; для закрытого профиля (видимость «подписчики») — запрос на подписку с подтверждением (допущение).
6. Реакции (одна — «огонь») и комментарии до 500 символов (допущение); автор может отключить комментарии к посту и удалить любой комментарий под своим постом.
7. **Авто-посты достижений**: при новом значке, рекорде, вехе, завершении челленджа приложение предлагает черновик поста; публикуется **только после нажатия «Опубликовать»**. Можно навсегда отключить предложения.
8. **Запрещено** автоматически публиковать: вес, замеры, фото прогресса, дневник питания, норму, активность. Пользователь может вручную загрузить своё фото, но **фото прогресса** из приватного хранилища в пост прикрепить нельзя (допущение — чтобы исключить случайную утечку; нужно загрузить файл заново).
9. Тренер не может публиковать ничего о клиенте (фото, результаты, имя) без отметки клиента и его подтверждения: отметка клиента в посте отправляет запрос, пост с отметкой виден только после согласия (допущение).
10. Изображения: EXIF (включая геотеги) удаляется при загрузке (допущение).
11. Блок пользователя: взаимное скрытие постов, комментариев, профилей; отписка обеих сторон; заблокированный не узнаёт о блоке.

### Модерация
12. Жалоба на пост/комментарий/профиль с причиной (спам, оскорбления, нагота, опасный контент, иное) → очередь в админ-панели.
13. Действия админа: оставить, скрыть контент, предупреждение, временный запрет публикаций (1/7/30 дней), бан из сообщества (допущение). Все действия — в журнале; автору — уведомление с причиной; апелляция — через кнопку обратной связи.
14. Автоскрытие (допущение): контент с ≥ 3 жалобами от разных пользователей скрывается до решения админа.
15. Базовый автофильтр (допущение): ссылки от аккаунтов младше 7 дней не публикуются; лимит 20 постов и 200 комментариев в сутки.

### Критерии приёмки
1.1. Пост с видимостью «подписчики» не виден неподписанному пользователю ни в стене, ни через API (RLS-тест).
1.2. Пост «только я» виден только автору.
1.3. Получение значка показывает предложение поста; без нажатия «Опубликовать» пост не создаётся.
1.4. Ни одно событие (новый замер, фото прогресса, запись дневника) не создаёт пост — проверяется e2e-тестом с подписчиком.
1.5. Фото прогресса нельзя выбрать в редакторе поста.
1.6. Загруженное изображение после публикации не содержит EXIF GPS.
1.7. Заблокированный пользователь не видит стену заблокировавшего; его комментарии скрыты.
1.8. Третья жалоба от разных пользователей скрывает пост; админ видит его в очереди.
1.9. Отметка клиента тренером не делает пост видимым до подтверждения клиента.

## 2. Поиск бадди

### Истории
- Пользователь: ищу партнёра для бега / зала по уровню, расписанию и району.
- Пользователь: мой контакт открывается только тому, кто тоже заинтересовался мной.

### Правила (Q49)
1. Доступ только 18+: подтверждение даты рождения при включении; младше 18 — раздел недоступен.
2. Анкета бадди (включается вручную, по умолчанию выключена): виды спорта (из списка), уровень (новичок / средний / продвинутый), удобное время (дни недели × утро/день/вечер), **примерная область** (см. раздел 3), радиус поиска (2/5/10/25 км — допущение), необязательно — пол и предпочитаемый пол партнёра, короткое «о себе» (до 300 символов).
3. Выдача: карточки с именем, аватаром, спортом, уровнем, временем и **примерным расстоянием** корзинами: «< 2 км», «2–5 км», «5–10 км», «10–25 км» (допущение). Точная дистанция и координаты не передаются клиенту.
4. Фильтр по полу применяется только если пользователь указал свой пол и предпочтение (Q49 «пол по желанию»); не указавшие пол не попадают в выдачу с фильтром по полу (допущение).
5. «Интересно» / «Пропустить». **Взаимный интерес** → обе стороны получают уведомление и **открывается контакт** — кнопка Telegram-чата (или «Попросить связаться», Q39).
6. До взаимности другая сторона не знает об интересе.
7. Лимит 30 «Интересно» в сутки (допущение). «Пропустить» скрывает карточку на 30 дней (допущение).
8. Блок и жалоба на карточке и после взаимности; блок отменяет взаимность и скрывает обоих друг от друга навсегда.
9. Выключение анкеты мгновенно убирает пользователя из выдачи; существующие взаимности сохраняются (допущение).

### Критерии приёмки
2.1. Пользователь 17 лет не может открыть раздел (UI и API).
2.2. Ответ API выдачи не содержит координат и точных расстояний — только корзину.
2.3. Односторонний «Интересно» не уведомляет вторую сторону.
2.4. Взаимный «Интересно» уведомляет обоих через бот и показывает кнопку связи.
2.5. Блок после взаимности убирает кнопку связи у обеих сторон.
2.6. Пользователь с выключенной анкетой отсутствует в выдаче.
2.7. 31-й «Интересно» за сутки отклоняется с сообщением о лимите.

## 3. Местоположение (общие правила для бадди, клубов, каталога)

1. Точная позиция с устройства (если пользователь разрешил геолокацию) используется **только на устройстве**: клиент округляет её до ячейки сетки ~1 км (допущение: геохеш длины 6 или аналог) и отправляет на сервер только ячейку. Альтернатива — выбор города/района вручную.
2. Сервер хранит только ячейку или выбранный район; расстояния считаются между центрами ячеек (PostGIS) и выдаются корзинами.
3. Для клубов хранится адрес и координаты **клуба** (это публичное место), не пользователя.
4. Пользователь может в любой момент очистить сохранённую область.
5. Геокодирование — открытые геокодеры (Q52); запросы от сервера, без передачи идентификаторов пользователя (допущение).

### Критерии приёмки
3.1. В БД нет колонок/записей с точными координатами пользователя (ревью схемы + тест: запрос с точными координатами сохраняет только ячейку).
3.2. Ручной выбор города работает без разрешения геолокации.
3.3. «Очистить местоположение» удаляет ячейку; пользователь пропадает из выдачи по расстоянию.

## 4. Карта клубов

### Истории
- Пользователь: вижу на карте залы рядом и тренеров, которые там работают.
- Тренер: добавляю свой зал, чтобы клиенты меня находили.
- Админ: проверяю добавленные клубы.

### Правила (Q52)
1. Карта: **MapLibre** + тайлы **OpenFreeMap**; атрибуция OSM/OpenFreeMap на карте; тема карты соответствует теме приложения (допущение).
2. **Клуб**: название, адрес, координаты (из открытого геокодера с ручной корректировкой пина), тип (зал, студия, бассейн, площадка, иное — допущение), необязательно сайт и фото.
3. Клубы добавляет **тренер**; новый клуб в статусе «на модерации» виден только добавившему; после одобрения админом — всем. Отклонение — с причиной.
4. Дубликаты: при добавлении предлагаются клубы в радиусе 200 м с похожим названием (допущение); админ может объединить дубликаты.
5. Тренер привязывает к себе клубы, где работает (к **локациям** волны 1); на карточке клуба — список верифицированных тренеров с публичной витриной.
6. Изменения данных одобренного клуба тренером тоже проходят модерацию (допущение).
7. Хранение и геопоиск — PostGIS; кластеризация меток на мелком масштабе.

### Критерии приёмки
4.1. Карта отображается с атрибуцией OpenFreeMap/OSM в обеих темах.
4.2. Клуб, добавленный тренером, не виден другим до одобрения админом.
4.3. Одобренный клуб виден на карте и в поиске; на его карточке — привязанные тренеры.
4.4. Добавление клуба рядом с существующим похожим показывает предупреждение о дубликате.
4.5. Отклонённый клуб показывает тренеру причину.
4.6. Карта работает плавно (60 fps при панорамировании) на среднем Android с 500 метками (допущение).

## 5. Каталог: поиск тренеров рядом

### Истории
- Человек без тренера: ищу тренера по виду тренировок, району, формату и цене.
- Тренер: попадаю в каталог и получаю заявки.

### Правила
1. В каталог попадают только **верифицированные** тренеры, включившие «Показывать в каталоге» (по умолчанию выключено — допущение).
2. Карточка: имя, фото, специализации, формат (офлайн / онлайн), клубы/районы, цена от (минимальная цена за занятие из **ценовой сетки**), рейтинг и число отзывов, языки, ссылка на **витрину**.
3. Фильтры: специализация, формат, расстояние (корзины, раздел 3) или город, цена (диапазон), язык, рейтинг от, наличие пробного занятия.
4. Сортировка: по расстоянию, рейтингу, цене. По умолчанию — по расстоянию для офлайн и по рейтингу для онлайн (допущение).
5. Ранжирование не продаётся в волне 4 (допущение).
6. Открытие витрины → «Записаться на пробное» (раздел 7) или «Написать» (Telegram-чат / «Попросить связаться»).

### Критерии приёмки
5.1. Неверифицированный тренер или тренер с выключенным каталогом не появляется в выдаче.
5.2. Фильтр «онлайн» показывает только тренеров с онлайн-форматом, без требования местоположения.
5.3. «Цена от» совпадает с минимальной ценой за занятие в ценовой сетке тренера.
5.4. Поиск без геолокации работает по выбранному городу.

## 6. Публичные отзывы и рейтинг

### Правила (Q53, сбор — с волны 2)
1. Публично показываются только отзывы, автор которых **согласился** на публикацию (Q53, было O5): при запуске каталога каждому автору отзыва волны 2 бот и приложение один раз задают вопрос «Опубликовать ваш отзыв о <тренер>?»; без ответа или при отказе отзыв остаётся непубличным. Новые отзывы волны 4 спрашивают согласие при отправке. Показ — на витрине (когда она публична) и в каталоге.
2. Автор показывается как имя + первая буква фамилии и аватар (допущение); клиент может сделать отзыв анонимным («Клиент DaFit») — допущение.
3. **Рейтинг** — среднее оценок публичных отзывов (с согласием автора), 1 знак после запятой; показывается при ≥ 3 таких отзывах, иначе «Мало отзывов» (допущение).
4. Публичный ответ тренера показывается под отзывом.
5. Скрытые админом отзывы не показываются и не участвуют в рейтинге. Споры — через админа (как в волне 2).
6. Сортировка отзывов: новые сверху; фильтр по оценке (допущение).

### Критерии приёмки
6.1. Тренер с 2 отзывами показывает «Мало отзывов», с 3 — рейтинг.
6.2. Отзывы 5, 4, 4 → рейтинг 4,3.
6.3. Скрытый админом отзыв не виден публично и не меняет рейтинг.
6.4. Анонимный отзыв не раскрывает имя автора в публичном API.
6.5. Отзыв волны 2 без согласия автора не виден публично и не входит в публичный рейтинг; после согласия — виден.
6.6. Вопрос о публикации задаётся автору ровно один раз.

## 7. Пробные занятия через каталог

### Истории
- Человек из каталога: записываюсь на пробное занятие в пару кликов.
- Тренер: получаю заявку на пробное с анкетой.

### Правила (Q51)
1. Тренер включает пробное: формат, длительность, цена (может быть 0), слоты для пробных (из своего расписания), лимит пробных на человека — одно у одного тренера (допущение).
2. Механика повторяет **ссылку на пробное** волны 1: выбор слота → вход через Telegram → **анкета** → **запись** на пробное; новый человек становится клиентом в **паре** с тренером.
3. Подтверждение: по настройке тренера — автоматически или вручную (по умолчанию вручную — допущение).
4. Источник клиента помечается «каталог» для аналитики тренера.
5. Правила отмены — как для обычных занятий; неявка на пробное без списания (абонемента нет), но отмечается (допущение).

### Критерии приёмки
7.1. Из карточки каталога пользователь записывается на пробное; после подтверждения тренером создаются пара и запись.
7.2. Повторная запись на пробное у того же тренера отклоняется.
7.3. Клиент из каталога помечен источником «каталог».

## Сквозные пограничные случаи

| Случай | Поведение |
|---|---|
| Клиент и тренер в паре, клиент заблокировал тренера в сообществе | Блок действует только в сообществе; пара и расписание не затрагиваются (допущение). |
| Пользователь удаляет аккаунт | Посты, комментарии, реакции, анкета бадди, взаимности удаляются; отзывы — по правилам волны 2. |
| Тренер теряет верификацию | Исчезает из каталога и с карточек клубов; посты остаются. |
| Клуб закрылся | Тренер или админ помечают «закрыт»; клуб скрывается с карты после одобрения админом. |
| Контент на двух языках | Посты не переводятся; интерфейс — RU/EN. |
| Экспорт данных | Включает посты, комментарии, подписки, анкету бадди, взаимности, добавленные клубы (Q44). |

## Вне волны

- Алгоритмическая лента и рекомендации.
- Платное продвижение в каталоге.
- Внутренний чат (только Telegram, Q39).
- Видео в постах (допущение: только изображения).
- Эквайринг и оплата пробного через платформу — после беты.
- Студии как организации в каталоге.
- Отдельный контур данных РФ — до официального запуска в РФ.

## Допущения

1. Сигналы успеха: ≥ 20% активных открывают ленту еженедельно; ≥ 1 пробное через каталог на тренера в месяц.
2. Видимость профиля (все / подписчики / никто) выбирается при первом входе в сообщество.
3. Лента — 16+.
4. Пост: до 2000 символов, до 10 изображений; видимость по умолчанию «подписчики».
5. Лента хронологическая, без ранжирования.
6. Запрос на подписку для закрытого профиля.
7. Одна реакция, комментарии до 500 символов.
8. Фото прогресса нельзя прикрепить к посту из приватного хранилища.
