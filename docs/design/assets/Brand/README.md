# Brand

- `da-mark.svg`: Да-отметка, кольцо, из которого выходит галочка. Знак одноцветный, `#3d63ff` (значение `accent` в тёмной теме), и читается на `bg` обеих тем. Минимальный размер 16 px. Знак не перекрашиваем в цвета данных, не обводим и не ставим на фото.
- `app-icon.svg`: иконка приложения и аватар бота. Знак стоит на чёрном (`bg` тёмной темы) со скруглением, как у иконок iOS. Файл используем как есть.

Словесного логотипа пока нет, название DaFit рабочее. До финального названия его набираем шрифтом Onest 700 цветом `ink`, без значка внутри слова.
