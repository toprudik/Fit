# Chip

Фильтр или выбор, в котором можно отметить несколько значений сразу.

Принимает `selected`, `icon` и `onClick`, текст передаётся дочерним элементом.

Выбранный чип красится в `inverse` с текстом `on-inverse` и получает галочку, так выбор видно и без цвета. Чипы ставим одной прокручиваемой строкой над списком.
