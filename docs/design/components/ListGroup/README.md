# ListGroup

Сгруппированный список на `surface-1` со скруглением `radius-lg`. На нём держатся настройки, карточка клиента и расписание.

`header` подписывает группу обычным регистром, без капса. `footer` добавляет пояснение снизу. Внутрь кладутся `ListRow`, `SessionRow` или свои строки.

Разделители рисуются токеном `line` и начинаются с отступом под иконку. Карточку в карточку не вкладываем, группа сама по себе карточка.
