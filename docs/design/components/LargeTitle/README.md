# LargeTitle

Шапка экрана с крупным заголовком, который при прокрутке сворачивается до 17 px.

`title` и `subtitle` (дата или контекст: «на проверке», имя клиента). Слева на корне вкладки ставится `avatar`: это имя для аватара-кнопки «Профиль», которая открывает профиль и переключатель зон. На вложенном экране сайта вместо него `back` с подписью кнопки «Назад» и обработчиком `onBack`. Справа идут дочерние элементы или `actions`, не больше двух `IconButton`. Остальное убираем в меню «Ещё».

Фон шапки `material` с размытием. В Telegram вместо своей кнопки «Назад» работает системная BackButton, а цвет шапки Telegram совпадает с `bg`. На десктопе вместо крупного заголовка показываем хлебные крошки.
