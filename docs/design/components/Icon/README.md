# Icon

Иконки Lucide, тот же набор, что в приложении (`lucide-react`).

`name` берётся из списка `DaFit.icons`. `size` 16 для плотных мест, 20 в тексте и кнопках, 24 в навигации. `strokeWidth` по умолчанию 1.75, для активной вкладки и мелких размеров от 2 до 2.25. `label` нужен, если иконка стоит без текста и что-то значит.

На одном экране держим одну толщину линии, залитые иконки не используем. Цвет иконка берёт у текста через `currentColor`.
