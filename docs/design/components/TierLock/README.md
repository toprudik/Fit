# TierLock

Функция более дорогого тарифа. Её видно, рядом объяснение и кнопка «Запросить доступ».

Принимает `tier` со значением `pro` или `premium`, `title` с названием функции, `description` с тем, что она даст человеку, `onRequest` и `requested`, если заявка уже отправлена.

Функции тарифа мы не прячем, а показываем с замком. В бете цен нет, кнопка отправляет заявку админам. Тот же компонент встаёт на место недоступного графика или блока.
