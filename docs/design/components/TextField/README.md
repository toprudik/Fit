# TextField

Поле ввода с подписью сверху и подсказкой или ошибкой снизу.

Принимает `label`, `hint`, `error` (заменяет подсказку и красит рамку в `danger`) и `suffix` с единицей измерения («кг», «₽», «мин»). Всё остальное уходит в `<input>`: `value`, `onChange`, `inputMode="decimal"` для чисел.

Подпись видна всегда, плейсхолдер её не заменяет. Ошибка объясняет, что не так и как исправить: «Введи вес от 30 до 300 кг». Для чисел задаём `inputMode`, чтобы на телефоне открывалась цифровая клавиатура.
