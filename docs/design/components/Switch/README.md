# Switch

Переключатель «вкл/выкл», который срабатывает сразу.

Принимает `checked` или `defaultChecked`, `onChange`, `label` и `showLabel`, чтобы показать подпись строкой слева. Так делаем в списках настроек.

Подходит только для настроек, которые применяются мгновенно. Если изменение потом подтверждают кнопкой «Сохранить», в форме нужен `SegmentedControl` или `Chip`. Включённый переключатель красится в `accent`, выключенный в `line-strong`, чтобы белый бегунок читался в обеих темах с контрастом от 3:1.
