# DaRing

Да-отметка, фирменное кольцо статуса занятия. По ходу занятия кольцо заполняется, а когда тренер отмечает занятие, замыкается, и из него выходит галочка.

`state` принимает `scheduled`, `progress` (вместе с `value` от 0 до 1), `done`, `missed` и `cancelled`. `size` в строках 24 или 28, в карточках 44, в крупном блоке от 64 до 120. `animate` проигрывает отметку при появлении. `label` задаёт свою подпись для диктора, по умолчанию это «Проведено», «Неявка» и так далее.

Это единственная громкая анимация продукта. Она играет только в ответ на действие человека: отметил занятие, закрыл подход, дошёл до вехи. В Telegram её сопровождает вибро `notificationOccurred('success')`. Сама по себе, например при загрузке списка, анимация не запускается. Если включено «уменьшить движение», кольцо сразу показывается в конечном виде, а вибро остаётся.
