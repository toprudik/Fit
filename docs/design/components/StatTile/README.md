# StatTile

Плитка с одним показателем: подпись, крупная цифра Tektur Narrow и изменение.

Принимает `label`, `value` (уже отформатированная строка, например «38 400»), `unit` («₽», «кг»), `delta` («+12%», «−1,4 кг»), `deltaDirection` со значением `up` или `down` (без него направление берётся из знака), `deltaTone` (`up` для хорошего изменения цветом `success`, `down` для плохого цветом `danger`, `flat` для нейтрального) и `caption` («за неделю»).

Цвет изменения зависит от смысла. Если клиент худеет, «−1,4 кг» получает `deltaTone: "up"`. Значение форматируется по локали, в русском тысячи отделяются пробелом. На одном экране не больше четырёх плиток.
