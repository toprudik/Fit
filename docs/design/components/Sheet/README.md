# Sheet

Нижняя шторка для короткого действия поверх экрана: подтверждения, выбора или быстрой формы.

Принимает `title`, `description`, дочерние элементы и `actions` с кнопками внизу, главная идёт первой.

Шторка выезжает снизу на пружине и закрывается свайпом вниз или тапом по затемнению (`scrim`). Необратимое действие, например списание или удаление, делаем только через шторку, где объяснено, что будет дальше. На десктопе шторка превращается в диалог по центру шириной 480 px.
