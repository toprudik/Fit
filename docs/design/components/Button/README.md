# Button

Кнопка действия. Кнопка `primary` на экране может быть только одна.

На кнопке пишем глагол, по которому ясно, что случится: «Записаться», «Отметить: был», «Списать занятие». После действия тост повторяет тот же глагол: «Записано», «Отмечено».

`variant` задаёт вид: `primary` с заливкой `accent`, `secondary` на `surface-2`, `ghost` с текстом `accent-ink` для второстепенных действий в шапке и строках, `destructive` (`danger-soft` и `danger`) только для необратимого. `size` бывает `sm` (36 px), `md` (44 px) и `lg` (52 px, нижняя кнопка экрана). `block` растягивает кнопку на всю ширину. `loading` показывает спиннер вместо иконки и сохраняет ширину. `icon` принимает имя иконки Lucide, она встаёт слева.

При нажатии кнопка уменьшается до `scale(0.97)` за `duration-instant`. В Telegram главная кнопка вызывает вибро `impact light`. Стрелку «→» в текст не ставим. Две синие кнопки рядом тоже не ставим, вторая будет `secondary`.
