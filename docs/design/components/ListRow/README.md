# ListRow

Строка списка с иконкой, заголовком, подзаголовком и значением. Если строка ведёт дальше, справа появляется шеврон.

`icon` и `iconTone` (`accent` даёт синюю плитку для главного пункта). `avatar` принимает имя человека и ставит слева аватар 40 px, фото передаётся в `avatarSrc`. Дальше `title`, `subtitle` и `value` с табличными цифрами. `badge`, `badgeTone` и `badgeIcon` добавляют метку статуса справа. С `onClick` или `href` появляются шеврон и подсветка нажатия. Для своих элементов есть `leading` и `trailing`, например для `Switch`.

Высота строки от 52 px, нажимается вся строка целиком. Значение справа пишем цветом `ink-2`, синим его не делаем. Строка клиента устроена так: `avatar`, в `subtitle` следующее занятие, в `badge` то, что требует внимания («Долг: 1», «Осталось 2»).
