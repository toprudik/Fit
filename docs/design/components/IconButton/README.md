# IconButton

Круглая кнопка с иконкой 44×44 для действий в шапке и строках.

`icon` берёт имя из Lucide. `label` обязателен: это имя кнопки для экранного диктора, например «Добавить занятие». `variant` по умолчанию `ghost`, а `secondary` добавляет подложку `surface-2`.

Подходит только для действий, которые все узнают по иконке: добавить, поиск, настройки, ещё. Если действие не очевидно, нужна `Button` с текстом.
