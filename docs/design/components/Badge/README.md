# Badge

Короткая метка статуса или тарифа рядом с названием.

`tone` бывает `neutral`, `accent`, `success`, `warning`, `danger`, `pro` и `premium`. `icon` добавляет иконку слева. Текст передаётся дочерним элементом, а для `pro` и `premium` подставляется сам.

В метке одно или два слова. Цвет статуса всегда идёт вместе со словом. Pro синий, Premium золотой.
