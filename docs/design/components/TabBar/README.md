# TabBar

Нижняя панель разделов зоны, до пяти вкладок. Закреплена поверх контента.

Принимает `items` в виде `[{id, label, icon}]`, `value` или `defaultValue`, `onChange` и `label`.

В зоне тренера вкладки «Сегодня», «Расписание», «Клиенты», «Деньги» и «Ещё», в зоне клиента «Главная», «Занятия», «Дневник», «Прогресс» и «Тренеры». У активной вкладки иконка цвета `accent-ink` с более толстой линией и подпись цвета `ink`. Повторное нажатие на активную вкладку прокручивает экран к началу. Вкладки меняются кроссфейдом за `duration-fast`, без сдвига. От 768 px вместо таб-бара появляется боковое меню.
