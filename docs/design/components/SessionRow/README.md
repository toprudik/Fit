# SessionRow

Строка занятия в расписании: время, с кем, где и Да-кольцо со статусом.

Принимает `time` («18:30»), `duration` («60 мин»), `title` (клиент или группа), `subtitle` (место, «Онлайн» или «6 из 8 мест»), `format` со значением `offline` или `online` (от него зависит иконка), `state` с теми же значениями, что у `DaRing`, `value` с прогрессом и `onClick`.

Время стоит отдельной колонкой табличных цифр, по ней выравниваются все строки. Отменённое занятие остаётся в дне, только зачёркнутое и серое. Свайп по строке на телефоне открывает действия «Отметить: был» и «Неявка».
