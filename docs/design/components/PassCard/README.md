# PassCard

Карточка абонемента. Показывает, сколько занятий осталось, до какого числа он действует и есть ли долг. Для клиента это главная цифра.

Принимает `title` («Персональные, 10 занятий»), `subtitle` (тренер или клиент), `total`, `left`, `debt` (сколько занятий в долг), `expires` («до 12 декабря»), `price` («3 500 ₽ за занятие»), а также `status` и `statusTone`, например «Заморожен».

Остаток нарисован как блины на грифе: синие ещё остались, серые уже использованы, красные взяты в долг. Если занятий больше 20, вместо блинов идёт сплошная полоса. При долге главная цифра равна нулю, а сам долг словами показывает бейдж.
