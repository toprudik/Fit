# SegmentedControl

Переключатель на два, три или четыре вида одного экрана. Выбран всегда ровно один.

`options` задаёт варианты в виде `[{value, label}]`. Дальше `value` или `defaultValue`, `onChange` и `label` с названием группы для диктора.

Выбранный сегмент отмечается инверсным бегунком (`inverse` и `on-inverse`). Выбранное в DaFit всегда показываем инверсией, синий оставляем для действий. Бегунок переезжает за `duration-base` с `easing-standard`, в Telegram при этом срабатывает вибро `selection`. Если в фильтре можно выбрать несколько значений, нужны `Chip`, сегменты для этого не подходят.
