# Шрифты для картинок карточек

Статичные TTF-срезы шрифтов приложения для `/api/story/[id]`: рендер картинок `next/og` не читает woff2 и переменные шрифты. Сделаны из `../onest-variable.woff2` (вес 500 и 700) и `../tektur-narrow.woff2` (вес 700) через fontTools: экземпляр по оси веса и подмножество знаков (латиница, кириллица, знаки препинания и минус). Лицензии те же, OFL: `../OFL-Onest.txt` и `../OFL-Tektur.txt`.
